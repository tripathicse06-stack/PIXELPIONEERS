# BrickByte 2026

**Build for Bharat. Brick by brick.**

A landing page for a fictional 24-hour hybrid hackathon at MMMUT, Gorakhpur.
Built for Prompt 2 Pixel, Round 2, Problem Statement 02 (Tech Event / Hackathon Landing Page).

## Links

- Live site: https://brickbyte2026-pixelpioneers.vercel.app/
- GitHub: https://github.com/tripathicse06-stack/PIXELPIONEERS

> All event names, prizes, sponsors and contacts are fictional samples.
> The registration form is a front-end demo. Nothing is sent or stored.

## Sections

| Section | Contents |
|---|---|
| Navbar | Logo, section links, Register button, mobile menu |
| Hero | Event name, tagline, date, venue, hybrid format, live countdown |
| About | Overview, goals, who can join |
| Tracks | 4 tracks with icons and descriptions |
| Schedule | 11 timed activities across 2 days |
| Mentors | 4 sample mentor and judge cards |
| Prizes | 4 prize cards, labelled as sample values |
| Sponsors | 4 logo placeholders, labelled as sample |
| FAQ | 6 questions in an accordion |
| Register | Call to action with a validated form |
| Footer | Contact, social links, quick links |

## Features

- Live countdown to the event start
- Filterable tracks and schedule
- Registration form with validation
- Responsive layout with no horizontal overflow
- Accessible: skip link, ARIA labels, alt text, keyboard support

## Tech

HTML5, CSS3 and vanilla JavaScript. No frameworks, libraries or templates.
All artwork is original inline SVG.

## Files

| File | Purpose |
|---|---|
| `index.html` | Structure and content |
| `style.css` | Styling and responsive rules |
| `script.js` | Countdown, filters, FAQ, form validation, menu |
| `mmmut-logo.png` | Host university emblem |

## Run locally

Open `index.html` in any browser. No setup is needed.
